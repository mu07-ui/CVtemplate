# 个人作品集网站 · 验收标准（Acceptance Criteria）

> 版本：v1.0 ｜ 日期：2026-09-02
> 本文档由三轮事件风暴收敛的需求生成，是开发与验收的唯一基准。
> 每条标准均带编号（AC-x.y），可追溯至测试用例（见 `tests/`）。

---

## AC-1 编辑器布局

| 编号 | 验收标准 | 验证方式 |
|---|---|---|
| AC-1.1 | 编辑器页面为左右分栏：左侧编辑面板占 25%，右侧预览画布占 75%（比例 1:3） | 组件测试 / 手动测量 |
| AC-1.2 | 编辑器为独立路由 `/editor`，与展示页 `/index` 完全分离 | 路由测试 |
| AC-1.3 | 构建后的公开站点产物中不包含编辑器代码（懒加载分包，展示页 bundle 无 editor chunk） | 构建产物检查 |

## AC-2 自由画布

| 编号 | 验收标准 | 验证方式 |
|---|---|---|
| AC-2.1 | 元素位置与尺寸以百分比（相对画布宽高）存储，而非像素 | 单元测试 |
| AC-2.2 | 像素坐标与百分比坐标可互转（pxToPercent / percentToPx），误差 ≤ 0.01% | 单元测试 |
| AC-2.3 | 元素支持鼠标拖拽改变位置，位置实时更新且持久化 | 集成测试 |
| AC-2.4 | 网格吸附：开启后拖拽落点吸附到最近的网格线（默认网格 8px 当量，可配置） | 单元测试 |
| AC-2.5 | 吸附开关可切换；关闭时为自由落点 | 单元测试 |
| AC-2.6 | 透明背景 PNG 图片渲染后无白底、无黑色填充 | 手动验收 |
| AC-2.7 | 元素层级可通过属性面板调整（上移/下移/置顶/置底），渲染顺序随之变化 | 单元测试 |
| AC-2.8 | 展示页在手机端按屏幕宽度流式等比重排，无横向滚动条 | 手动验收 |

## AC-3 元素类型（七类）

| 编号 | 验收标准 | 验证方式 |
|---|---|---|
| AC-3.1 | 每类元素可由工厂函数创建，产物包含唯一 id、类型、位置（%）、尺寸（%）、层级 | 单元测试 |
| AC-3.2 | 文本元素：支持编辑文字内容、字号、颜色 | 单元测试 |
| AC-3.3 | 图片元素：支持本地上传（FileReader → dataURL）与 URL 两种来源 | 单元测试 |
| AC-3.4 | 视频元素：来源为「外链嵌入」或「本地上传」二选一；外链需为 B站/YouTube 合法嵌入格式 | 单元测试 |
| AC-3.5 | 链接卡片元素：含标题、URL；点击后在新标签页打开 | 单元测试 / 手动验收 |
| AC-3.6 | 技能标签元素：支持增删标签项，每项含名称 | 单元测试 |
| AC-3.7 | 相册元素：支持多图列表，点击进入灯箱大图浏览 | 单元测试 |
| AC-3.8 | 装饰元素：至少支持 色块 / 线条 / 图标 三种，可设透明度 | 单元测试 |
| AC-3.9 | 任意元素数据可通过 `validateElement` 校验：未知类型、越界坐标（<0 或 >100）、非法 URL 均校验失败 | 单元测试 |

## AC-4 主题系统

| 编号 | 验收标准 | 验证方式 |
|---|---|---|
| AC-4.1 | 内置三套主题：商务稳重（business）/ 玻璃拟态（glass）/ 复古像素（pixel） | 单元测试 |
| AC-4.2 | 每套主题提供完整的 CSS 变量集（背景、前景、主色、圆角、阴影、字体），无缺失字段 | 单元测试 |
| AC-4.3 | 切换主题即时生效（无刷新），且写入持久化数据 | 单元测试 |
| AC-4.4 | 当前主题为持久化数据的一部分，导入 JSON 后主题随之恢复 | 单元测试 |
| AC-4.5 | 科技氛围背景层：细网格 + 星座节点连线 + 暗角分层叠加在主题渐变之上，缓慢漂移动画；展示页 / 编辑器预览 / 导出静态页三层一致 | 组件测试 |

## AC-5 编辑辅助能力

| 编号 | 验收标准 | 验证方式 |
|---|---|---|
| AC-5.1 | 撤销：Ctrl+Z 回退到上一历史状态；重做：Ctrl+Shift+Z 前进 | 单元测试 |
| AC-5.2 | 历史栈上限 50 条，超限丢弃最旧记录 | 单元测试 |
| AC-5.3 | 快捷键：Delete 删除选中元素、方向键微调位置（1px，Shift+方向键 10px）、Ctrl+D 复制元素 | 单元测试 |
| AC-5.4 | 复制的元素与源元素内容一致，但 id 不同且位置轻微偏移（避免完全重叠） | 单元测试 |

## AC-6 数据持久化与导入导出

| 编号 | 验收标准 | 验证方式 |
|---|---|---|
| AC-6.1 | 站点数据（元素列表 + 主题 + 画布配置）序列化为单一 JSON 对象，含 `version` 字段 | 单元测试 |
| AC-6.2 | 数据自动保存至 localStorage，键名 `portfolio-site-data`；刷新后完整恢复 | 单元测试 |
| AC-6.3 | 「导出 JSON」下载完整数据文件；「导入 JSON」可还原全部数据（含素材 dataURL） | 单元测试 |
| AC-6.4 | 导入非法 JSON / 缺失 version 字段时给出中文错误提示且不破坏现有数据 | 单元测试 |
| AC-6.5 | 「导出静态站」产出 ZIP：含 index.html、assets、数据文件，双击 index.html 可离线浏览 | 手动验收 |
| AC-6.6 | 「导出 PDF」基于独立 A4 简历模板生成：抽取文本类信息（姓名/简介/技能/链接），作品图缩略展示 | 手动验收 |

## AC-7 展示页与部署

| 编号 | 验收标准 | 验证方式 |
|---|---|---|
| AC-7.1 | 展示页纯静态、无后端依赖；`npm run build` 产物可直接部署到 GitHub Pages / Vercel | 构建验证 |
| AC-7.2 | 展示页渲染与编辑器预览一致（同一渲染组件复用） | 组件测试 |
| AC-7.3 | 初始内置示例内容：头像、简介、技能标签、≥3 个作品卡片、装饰元素 | 手动验收 |
| AC-7.4 | 界面语言为中文（含编辑器面板、按钮、错误提示） | 手动验收 |

## AC-8 视频与外链

| 编号 | 验收标准 | 验证方式 |
|---|---|---|
| AC-8.1 | B站/YouTube 视频外链解析为标准嵌入 iframe 地址 | 单元测试 |
| AC-8.2 | 本地上传视频以 dataURL 存储并可通过 `<video>` 播放 | 手动验收 |
| AC-8.3 | 所有外链（链接卡片/作品跳转）均带 `target="_blank"` 与 `rel="noopener"` | 组件测试 |

## AC-9 分区分页导航（官网式四分区）

| 编号 | 验收标准 | 验证方式 |
|---|---|---|
| AC-9.1 | 站点数据支持分区列表 `sections`：每项含名称与起始纵坐标（画布百分比 0~100），随 JSON 序列化持久化；未配置分区时不渲染分页组件 | 单元测试 |
| AC-9.2 | 分页组件包含：页码指示器（分区序号，桌面端附分区名称）、上一页/下一页按钮、点击页码可平滑跳转到对应分区 | 组件测试 |
| AC-9.3 | 滚动同步：滚动展示页时，页码指示器高亮当前所在分区（按滚动进度与分区起始坐标判定） | 单元测试 |
| AC-9.4 | 响应式：窄屏（≤640px）切换为紧凑模式（仅页码），且任意屏宽下无横向滚动条 | 手动验收 |
| AC-9.5 | 导出的静态站包含同款分页导航，页码/翻页/跳转/滚动高亮行为与展示页一致 | 单元测试 |
| AC-9.6 | 内置示例内容为四分区（首页 / 作品 /案例 / 项目）官网式版式，含示例图片（远程图源）与外链卡片；版式定稿后更新仅需替换内容，无需再调整定位 | 手动验收 |

## 验收流程

1. 单元测试全部通过：`npm run test`
2. 构建 SSR 无产物污染：`npm run build` 后检查 editor chunk 分包
3. 手动验收清单走查（AC-2.6 / 2.8 / 6.5 / 6.6 / 7.3 / 7.4 / 8.2）
