# 个人作品集网站 · 验收标准（Acceptance Criteria）

> 版本：v2.0 ｜ 日期：2026-09-10
> 本文档是开发与验收的唯一需求基准。每条标准带编号（AC-x.y），可追溯至测试用例（见 `tests/`）。
> 编号语义不可修改；被替代条目仅允许追加「废弃标注」（AGENTS.md 约定）。

## AC-1 编辑器布局

| 编号 | 验收标准 | 验证方式 |
|---|---|---|
| AC-1.1 | 编辑器页面为左右分栏：左侧编辑面板占 25%，右侧预览画布占 75%（比例 1:3） | 组件测试 / 手动测量 |
| AC-1.2 | 编辑器为独立路由 `/editor`，与展示页完全分离 | 路由测试 |
| AC-1.3 | 构建后的公开站点产物中不包含编辑器代码（懒加载分包，展示页 bundle 无 editor chunk） | 构建产物检查 |

## AC-2 自由画布

| 编号 | 验收标准 | 验证方式 |
|---|---|---|
| AC-2.1 | 元素位置与尺寸以百分比（相对画布宽高）存储，而非像素 | 单元测试 |
| AC-2.2 | 像素坐标与百分比坐标可互转（pxToPercent / percentToPx），误差 ≤ 0.01% | 单元测试 |
| AC-2.3 | 元素支持鼠标拖拽改变位置，位置实时更新且持久化 | 集成测试 |
| AC-2.4 | 网格吸附：开启后拖拽落点吸附到最近的网格线（默认网格 8px 当量，可配置） | 单元测试 |
| AC-2.5 | 吸附开关可切换；关闭时为自由落点 | 单元测试 |
| AC-2.6 | 透明背景 PNG 图片渲染后无白底、无黑色填充 | 手动验收 |
| AC-2.7 | 元素层级可通过属性面板调整（上移/下移/置顶/置底），渲染顺序随之变化 | 单元测试 |
| AC-2.8 | 展示页在手机端按屏幕宽度流式等比重排，无横向滚动条 | 手动验收 |

## AC-3 元素类型（基础七类）

| 编号 | 验收标准 | 验证方式 |
|---|---|---|
| AC-3.1 | 每类元素可由工厂函数创建，产物包含唯一 id、类型、位置（%）、尺寸（%）、层级 | 单元测试 |
| AC-3.2 | 文本元素：支持编辑文字内容、字号、颜色 | 单元测试 |
| AC-3.3 | 图片元素：支持本地上传（FileReader → dataURL）与 URL 两种来源 | 单元测试 |
| AC-3.4 | 视频元素：来源为「外链嵌入」或「本地上传」二选一；外链需为 B站/YouTube 合法嵌入格式 | 单元测试 |
| AC-3.5 | 链接卡片元素：含标题、URL；点击后在新标签页打开 | 单元测试 / 手动验收 |
| AC-3.6 | 技能标签元素：支持增删标签项，每项含名称 | 单元测试 |
| AC-3.7 | 相册元素：支持多图列表，点击进入灯箱大图浏览 | 单元测试 |
| AC-3.8 | 装饰元素：至少支持 色块 / 线条 / 图标 三种，可设透明度 | 单元测试 |
| AC-3.9 | 任意元素数据可通过 `validateElement` 校验：未知类型、越界坐标（<0 或 >100）、非法 URL 均校验失败 | 单元测试 |

## AC-10 多页路由信息架构

| 编号 | 验收标准 | 验证方式 |
|---|---|---|
| AC-10.1 | 展示站为多页路由站：`#/`（首页）、`#/works`（作品集）、`#/projects`（项目）、`#/about`（关于我）四页独立路由（hash 模式），支持浏览器前进/后退 | 路由测试 |
| AC-10.2 | 站点数据按页存储：`pages` 数组，每页含唯一 key、页名（双语）、元素列表与页面配置；路由 key 与数据 key 一一对应 | 单元测试 |
| AC-10.3 | 顶部导航（桌面/平板）高亮当前页，点击切换路由；手机端由底部标签栏承担（见 AC-11.2） | 组件测试 |
| AC-10.4 | 首页必备板块：英雄区（姓名/头衔/双语切换/CTA 按钮）、精选作品、数据亮点（统计条）、行动引导 | 手动验收 |
| AC-10.5 | 作品集必备板块：作品卡片网格（支持类型筛选）、灯箱大图、外链跳转 | 手动验收 |
| AC-10.6 | 项目页必备板块：项目案例卡（配图/简介/技术标签/外链） | 手动验收 |
| AC-10.7 | 关于我必备板块：个人介绍、个人时间线、技能矩阵、荣誉与证书、联系方式卡片 | 手动验收 |
| AC-10.8 | 四页均内置示例内容（接管原 AC-9.6 职责），版式定稿后更新仅需替换内容 | 手动验收 |
| AC-10.9 | 未匹配路由（如 `#/xxx`）重定向回首页 | 单元测试 |
| AC-10.10 | 每页底部「↓ 往下探索」为纯文本提示（不响应点击）；页面滚动到底后继续向下滚动滚轮进入下一页（首页→作品集→项目→关于我，末页不响应），带滚动累积阈值与翻页冷却以吸收触控板惯性；站内 hash 链接（`#/` 开头）在展示页与导出站中当前页跳转、不展示 url 明文，外链新标签打开 | 单元测试 |

   - 多页路由四页 + 未知路由重定向（AC-10）

   - 五主题 × 三档动效 × 移动端降级（AC-14 / AC-15）

   - 图层/对齐线/模板库/多选（AC-17）
