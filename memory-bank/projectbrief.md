# 项目简报（Project Brief）

## 一句话定位
无后端纯前端「个人作品集多页官网」——四页路由展示站（首页/作品集/项目/关于我，中英双语，三端自适应）+ PC 可视化工坊（自由画布、双态发布、一键部署包）。

## 核心目标（v2.0）
1. **展示**：四页路由站 `#/` `#/works` `#/projects` `#/about`，hash 模式，双语内容（{zh,en}，缺失回退中文）
2. **编辑**：PC 可视化工坊（25/75 分栏）——自由画布七类+四类结构化元素、双态（草稿/发布）+ 快照回滚、图层面板/智能对齐线/模板库/多选批量
3. **多端**：混合式响应式（内容流式缩放 + 断点重排），手机端底部标签栏；工坊仅 PC
4. **风格**：五套大跨度主题（曜蓝商务/星穹玻璃拟态/暗夜霓虹/极简晨白/复古像素）+ 自研 Canvas 2D 粒子引擎（星域连线/网格漂移/光斑浮动）+ 三档动效
5. **导出**：一键 ZIP 部署包（四页全量+双语+粒子运行时+部署指引）、JSON 备份、A4 PDF 简历
6. **约束**：零后端、零新增运行时依赖，GitHub Pages / Vercel 双平台兼容，导出包 file:// 离线可用

## 关键决策（v1 三轮 + v2 五轮事件风暴收敛）
| 决策点 | v1 结论 | v2.0 结论 |
|---|---|---|
| 页面架构 | 单长页 + 分区分页导航 | **多页路由站**（四页 hash 路由，AC-9 废弃） |
| 画布引擎 | 自由画布（类 Canva） | **保留并扩展**：页面维度（每页一份元素集） |
| 元素 | 七类 | 七类 + 四类结构化（时间线/技能矩阵/荣誉证书/联系卡片） |
| 响应式 | 流式等比缩放 | **混合式**：内容缩放 + 断点重排（640/1024）；手机底部标签栏 |
| 语言 | 仅中文 | **中/英双语**（内容级 i18n，编辑器界面保持中文） |
| 保存 | 自动保存 + 撤销重做 | **双态 + 快照**：草稿/发布分离，快照上限 20，还原=放弃草稿 |
| 主题 | 三套 | **五套大跨度** + 自带粒子/动效预设 |
| 动效 | CSS 科技背景层 | **Canvas 2D 自研粒子引擎**，三档可配（沉浸/标准/节能），自动降级 |
| 素材 | 本地上传 + 外链 | **外链为主**（localStorage 5MB 风险对策） |
| 部署 | ZIP 导出 | **一键 ZIP + 部署指引页**，双平台兼容，file:// 离线可用 |
| 技术栈 | Vite + Vue 3 + Vitest（TDD） | 不变，零新增运行时依赖 |
