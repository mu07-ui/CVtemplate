# 项目简报（Project Brief）

## 一句话定位
无后端的纯前端「个人作品集网站」——自由画布编辑器（左编辑 1 : 右预览 3）+ 纯静态公开展示页，替代传统简历。

## 核心目标
1. **展示**：个人信息、能力（技能标签）、作品（图片 + 视频），支持外链跳转（GitHub/博客等）
2. **编辑**：可视化自由画布——元素任意拖放、透明 PNG 素材、位置随意调整
3. **导出**：可部署静态站 ZIP、A4 简历模板 PDF、JSON 数据备份；支持本地上传素材
4. **风格**：中文界面，三套主题随时切换（商务稳重 / 玻璃拟态 / 复古像素）
5. **约束**：零后端、零登录，构建产物可部署到 GitHub Pages / Vercel 等任意静态托管

## 关键决策（三轮事件风暴收敛）
| 决策点 | 结论 |
|---|---|
| 编辑形态 | 自由画布型（类 Canva） |
| 画布策略 | 自适应流式，位置按百分比存储 |
| 模式切换 | 编辑器独立页面（/editor），展示页零编辑器暴露 |
| 元素组件 | 文本 / 图片 / 视频 / 链接卡片 / 技能标签 / 相册 / 装饰 共七类 |
| 视频来源 | 外链嵌入（B站/YouTube）+ 本地上传 二选一 |
| PDF | 独立 A4 简历模板，从画布数据抽取文字 |
| 技术栈 | Vite + Vue 3 + Vitest（TDD） |
| 交付节奏 | 验收标准 → 测试 → 实现 → 构建/部署 |
