# 产品上下文（Product Context）

## 为什么做
用户需要一个**替代简历**的个人作品集网站：传统简历（PDF/Word）难以承载图片、视频作品与外链，且无法随时更新。本产品让用户像做 PPT 一样自由排版个人展示页，公开 URL 即可分享。

## 解决的问题
- 简历无法展示视频/图片作品 → 画布上自由摆放图文视频
- 建站需要写代码 → 可视化编辑器，左侧面板改内容右侧即时预览
- 作品集网站难更新 → 数据存 localStorage，可导入导出 JSON 迁移
- 求职仍需传统简历 → 一键导出 A4 PDF 简历模板

## 目标用户与场景
- **创作者本人**（唯一编辑者）：本地打开 /editor 排版、上传素材、切主题、导出部署
- **访客**（HR、合作方、朋友）：手机或桌面浏览器访问公开 URL 浏览作品集、点击外链

## 用户体验要求
- 界面全中文，包括错误提示
- 编辑器：拖拽即所见、误操作可撤销（Ctrl+Z）、网格吸附帮助对齐
- 展示页：手机端自动流式缩放，无横向滚动
- 首次打开有预填示例内容（头像/简介/技能/3 个作品卡片），改一改即可用

## 竞品参照
Canva / 稿定设计（自由画布交互）、Notion 个人主页（结构化展示）、read.cv（作品集形态）。差异点：纯前端零后端、数据自己掌控、可导出传统简历 PDF。
